## 🎯 技術的な実装方針

### **コンポーネント分離の原則**
- **単一責任の原則**: 各コンポーネントは1つの責務のみ
- **適切な粒度**: 過度に細かく分離しない
- **再利用性**: 共通化可能な部分は適切に抽出

### **page.tsxでの条件分岐設計**
```typescript
export default function Home() {
  return (
    <PageContainer>
      {!isConnected ? (
        <WalletConnectionPrompt />
      ) : trustlineQuery.isLoading ? (
        <TrustlineStatusChecker />
      ) : trustlineQuery.data ? (
        <BotFiMainSection />
      ) : (
        <TrustlineSetupSection />
      )}
    </PageContainer>
  )
}
```

### **データフローの最適化**
- 共通ロジック → ユーティリティ関数
- 状態管理 → 必要最小限のClient Component
- データフェッチ → 可能な限りサーバーサイド

### **パフォーマンス向上のポイント**
- コンポーネントのメモ化
- 計算結果のメモ化
- 不要な再レンダリングの防止
- 適切なコード分割
